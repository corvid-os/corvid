# prompt-el

Folder roboczy z ewolucją promptu/designu dla **Nyxarch**. Projekt robiony
wspólnie, na razie w formie roboczej — dużo małych plików, docelowo
skompresowane do 3 i przeniesione do osobnego, prywatnego repo:

- `prompt.md` — finalny prompt/spec projektu
- `design.md` — ostateczny design systemu
- `code.md` — kod (instalator, konfiguracja archiso)

## Pliki robocze (obecny etap)

| Plik | Zawartość |
|---|---|
| [`design.md`](./design.md) | szkic decyzji projektowych, sekcje `TBD` do uzupełnienia |
| [`naming.md`](./naming.md) | propozycje nazwy/brandingu |
| [`wiki.md`](./wiki.md) | notatki/fragmenty z Arch Wiki i innej dokumentacji |
| [`links.md`](./links.md) | same linki referencyjne, bez komentarza |

## Workflow
Dorzucamy pliki i notatki na bieżąco, każdy swoje. Treść wiki/dokumentacji —
do `wiki.md`, same linki — do `links.md`, żeby nie zaśmiecać `design.md`.
Iterujemy, aż uznamy że design jest kompletny, potem kompresja do 3 plików
docelowych.
